# Breakpoint statements

```ebnf
BreakpointStatement =   "breakpoint" , ";"
                    ;
```

> [!WARNING]
> Requires `breakpoint` preview feature enabled.

A breakpoint statement compiles to a single `LD B, B` instruction at that point in the program. Loading `B` into
itself has no effect, so a program behaves identically with or without breakpoints, including on real hardware.
Many Game Boy emulators can be configured to pause execution when `LD B, B` executes, making it a software breakpoint
for debugging.

```quokka,preview=breakpoint
global COUNT: u8;

fn main() {
    COUNT = 1;
    breakpoint;
    COUNT += 1;
}
```

Breakpoints are never removed or reordered by optimization, and no other code generated by the compiler uses
`LD B, B`.

A breakpoint statement is not allowed inside a [constant declaration](../items/const-items.md), as constant
declarations are evaluated at compile time.
