# Introduction

This book is the definitive book on the Quokka programming language and development toolkit.

## What is Quokka programming language?

Quokka is a programming language designed to programs which target the Nintendo[^1] Game Boy[^2] or Game Boy Color. It
blends high level language concepts with low level assembly language to meet the needs developing for the constrained
hardware.

## Why use Quokka?

The truth is that if your primary desire is to develop a homebrew video game for the  Game Boy or Game Boy Color,
then you would be better served by using [RGBDS](https://rgbds.gbdev.io/) and programming in assembly. RGBDS is a
comphrensive suite of tools developed and hardened over decade. In contrast, Quokka is still in the early stages of
development, and is likely buggy and incomplete.

If your goal is to learn, understand and use a programming language designed for a highly constrained system, then
Quokka might be what you are looking for.

## How to read this book

This book consists of following sections:

- **User guide**: A practical guide for using the Quokka
- **Reference**: The specification for the Quokka programming language and manual for the development toolkit

The _user guide_ assumes that you’re reading it sequentially from front to back as later chapters build on concepts in
earlier chapters. In contract, the _reference_ does not assume it is being read sequentially, with each chapter being
cross-referencing other chapters to elaborate on related concepts.
